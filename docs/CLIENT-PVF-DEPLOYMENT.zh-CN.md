# 测试客户端 PVF 部署与恢复

这项功能只把已经生成并复查的独立 PVF 安装到 profile 指定测试客户端的 `Script.pvf`。它不处理 NPK、IMG、UI 或其他客户端文件。

## 使用流程

1. 先完成 `pvf-change apply` 和生成后重新检查。
2. 告诉 Agent 要部署到哪个测试客户端。
3. Agent 生成部署预览，说明当前版本、候选版本和备份；预览不修改客户端。
4. 关闭客户端和启动器，明确确认后再部署。
5. 测试结束后，可让 Agent 按同样的预览与确认流程恢复部署前版本。

普通用户不需要手工拼命令；Agent 应跟随工作台返回的下一步。

## 必须满足

- profile 已配置准确的客户端目录；
- 候选 PVF 来自成功的生成记录，并绑定输出 SHA256 和生成后复查；
- 客户端当前版本与本轮修改基线一致；
- 客户端和启动器已经关闭。

修改来源可以就是该客户端原有的 `Script.pvf`，但正式生成必须先把其内容寻址备份核对为不可变的受保护锚点。多轮修改必须继承上一轮生成记录。客户端基线不符时默认停止；主动切换基线不是普通迭代选项，需要另外确认。

部署前会备份客户端当前 PVF，部署后会再次核对 SHA256。恢复只接受对应部署前的准确备份；客户端出现未知变化时不会覆盖。

部署成功只证明文件安装正确，不证明游戏行为正确。仍需进游戏检查目标功能；触及中文等文字时还要检查名称、说明和界面是否乱码。
